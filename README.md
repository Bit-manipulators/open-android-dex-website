# open-android-dex-website

Basic website for **Open Android Dex** — a free, open-source Pokédex companion for Android.

## Structure

- `index.html` — main page
- `style.css` — styles
- `script.js` — basic interactivity
- `README.md` — this file

## Usage

Open `index.html` in your browser, or serve it with any static file server, e.g.:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
