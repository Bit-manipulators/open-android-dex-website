About

Open Android Dex is an open-source Android app that lets you browse Pokémon data right from your phone. No ads, no tracking — just a simple, community-driven Pokédex you can build and modify yourself.

Features

  • Browse Pokémon

    Search and view Pokémon details including types, stats, and abilities.

  • Offline-first

    Works without an internet connection once data is loaded.

  • Open Source

    Fully open-source on GitHub. Contribute, fork, or customize it.

  • Lightweight

    Minimal dependencies and a small install size.

Download

Grab the latest release from the GitHub repository or build it yourself from source.
